# Changelog

## v0.2.0-beta1

A test build of the new release process. The map features are the same as in `v0.1.0-test`.

- **Fewer commands.** `/ls` now lists only the commands meant for players: `toggle`, `copy` and `log clear`. The development tools are hidden; `/ls dev` turns them on until your next `/reload`, in case a bug report needs them.
- **Version in chat.** The login message now shows which version you have, for example `Lodestar: v0.2.0-beta1 loaded`.
- **Cleaner download.** The zip holds only the files the game loads, plus the readme, license and this changelog.
